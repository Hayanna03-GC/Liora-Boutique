# Liora Boutique

Tienda web de ropa femenina desarrollada con PHP, HTML, CSS y MySQL.

## Tecnologías utilizadas

* PHP
* HTML
* CSS
* MySQL
* phpMyAdmin
* Bootstrap Icons

## Funciones

* Catálogo de productos.
* Categorías de Blusas, Bodies y Tops.
* Información de productos.
* Colores y tallas disponibles.
* Registro de usuarios.
* Inicio y cierre de sesión.
* Carrito de compras.
* Formulario de compra.
* Área independiente para administrador.

## Base de datos

La base de datos fue realizada en MySQL y administrada mediante phpMyAdmin.

Los archivos SQL del proyecto contienen las tablas y datos de prueba necesarios para utilizar la base de datos.
